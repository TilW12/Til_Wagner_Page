## Project and Description
For my capstone project I am creating what I like to call a Hydration Station. This project will be a coffee table made from scratch with a pump and liquid underneath the table going up a tube through a little hole in the table and when I press a button the pump will pump the liquid into my cup. 
## Project Inspiration
For this project I came up with it by myself. As far as the project in general I had no inspiration but for the table I have inpsiration from this youtube video [**Youtube coffee table design**](https://www.youtube.com/watch?v=g0LAd-i_9qA&t=230s). For my punmp system my inspiration is from my bioengineering capstone from last year where I made an automatic watering system.
